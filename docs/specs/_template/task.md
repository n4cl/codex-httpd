# Task（詳細設計）

このドキュメントは「あるべき姿（詳細設計）」を記載する。
仕様変更があれば内容を更新する。

## 実装計画（チェックリスト）
用途に合わせて、次のどちらかの書式を使う。

### 1. Major task のみ
- [ ] {{NUMBER}}. {{TASK_DESCRIPTION}}
  - {{DETAIL_ITEM_1}} *(必要なときだけ詳細を書く)*
  - _Design ref: {{DESIGN_SECTION}}_

### 2. Major + Sub-task
- [ ] {{MAJOR_NUMBER}}. {{MAJOR_TASK_SUMMARY}}
- [ ] {{MAJOR_NUMBER}}.{{SUB_NUMBER}} {{SUB_TASK_DESCRIPTION}}
  - {{DETAIL_ITEM_1}}
  - {{DETAIL_ITEM_2}}
  - _Design ref: {{DESIGN_SECTION}}_ *(Designの該当セクション名を書く)*
