# Task（実装タスク）

## 実装計画（チェックリスト）
このタスクは実装タスクとして、**具体的に実装する内容を記載する**。
ここでの「定義する」は、ドキュメント作成ではなく実装として定義することを指す。
具体化できていない項目は「(C)」「(D)」で明示し、確定後に削除する。
タグを付ける場合は `{{STATUS_TAG}}` を末尾に付与する。
  - `(C)`: 要確認
  - `(D)`: 後回し
